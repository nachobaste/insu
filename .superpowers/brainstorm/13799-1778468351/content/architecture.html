Insu — System Architecture

Sub-project 1: Foundation + Marketplace Browse

Stack

Frontend
Next.js 14 (App Router)
TypeScript
Tailwind CSS
shadcn/ui components
Backend
Supabase (PostgreSQL)
Supabase Auth
Supabase Realtime
Supabase Edge Functions (Deno)
Payments
Stripe (USD / international)
Conekta (MXN / Mexico)
Webhooks → Edge Functions
Pricing & Oracles
Black-Scholes in Edge Functions
OpenWeatherMap / Tomorrow.io
Waze API (traffic/urban)
Manual admin override

Data Flow

Browser → Next.js App Router (SSR pages + Server Actions) → Supabase DB (read markets, positions, pools)
Buy flow → Server Action → Stripe/Conekta checkout → Webhook → Edge Function → insert position + update pool
Pricing → Edge Function (cron, every 15min) → fetch oracle data → Black-Scholes → update contract price
Payout → Edge Function (cron, every 5min) → check oracle trigger → auto-settle → Stripe/Conekta transfer
Realtime → Supabase Realtime → browser (live price/volume updates on browse page)

Pages (Sub-project 1 scope)

/ (Browse) Categories + contract cards grid, search, filters, live volume
/markets/[slug] Contract detail, price chart, buy/provide buttons
/buy/[slug] Hedger purchase flow (coverage tier, amount, payment)
/provide/[slug] Risk provider capital deposit flow
/dashboard Portfolio: active protections, positions, payout history
/admin Create contracts, manage triggers, manual override

Green = Sub-project 1 core. Red = later sub-projects, but designed now so DB schema supports them from day 1.
